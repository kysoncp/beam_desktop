# Beam Studio

Beam Studio is a Tkinter desktop beam-design tool. Set beam supports, span,
loads, and section to view reactions, shear, moment, and deflection, with
bending and deflection checks. Designs can be saved/opened, and results can be
exported as CSV or a PDF calculation sheet.

## Requirements

- Python 3.10 or newer, with Tkinter available
- NumPy and Matplotlib

Install the packages and start the app:

```powershell
python -m pip install -r requirements.txt
python app.py
```
